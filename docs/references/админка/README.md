# Макет админки

`mockup.html` — набросок админки на токенах проекта: цвета, шрифт, радиусы и шкала
отступов взяты из `frontend/tailwind.config.js`, а не подобраны на глаз. Это документ для
обсуждения, а не страница приложения: разметка статическая, данные вымышленные.

Открывается двойным щелчком — `mockup.css` лежит рядом.

Пересобрать стили после правки разметки:

```bash
cd frontend && npx tailwindcss -c tailwind.config.js \
  -i ../docs/references/админка/input.css \
  -o ../docs/references/админка/mockup.css \
  --content ../docs/references/админка/mockup.html --minify
```

## Что на экранах

1. **Курсы** — список с фильтрами, статусом публикации и счётчиками программы.
2. **Программа курса** — модули с вложенными лекциями, перетаскивание, работы курса.
3. **Лекция и материал** — форма урока и загрузка файла.
4. **Вопросы теста** — веса, верные варианты, запрет правки вопроса с попытками.
5. **Проверка работ** — список сдач и панель рецензии (экран преподавателя).
6. **Студенты и доступ** — ручная выдача и отзыв доступа до подключения оплаты.

## Откуда взяты решения

Раскладка «боковое меню + таблица» и редактор программы «модули с вложенными уроками и
перетаскиванием» — общее место инструментов этого класса; сверялся с тем, как устроены
курсовые билдеры Thinkific и Teachable (секции как модули, уроки внутри, порядок меняется
перетаскиванием) и с обзорами LMS-панелей.

* https://support.thinkific.com/hc/en-us/articles/360030371754-The-Thinkific-Course-Builder
* https://support.thinkific.com/hc/en-us/articles/37547732533655-Introducing-Thinkific-s-New-Course-Builder
* https://adminlte.io/blog/lms-dashboard-templates/

## Чего в макете намеренно нет

Аналитики и графиков. Панель нужна, чтобы наполнять курсы и проверять работы; цифры
посещаемости — отдельная задача, и до неё дашборд с графиками будет украшением.
